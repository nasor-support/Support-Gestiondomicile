FAQ

Gestion Domicile est-elle disponible sur Mac et iPhone ?

Oui. Gestion Domicile existe en version macOS et en version iOS. Les deux applications sont conçues pour utiliser les mêmes données lorsque la synchronisation iCloud est activée.

Ai-je besoin d’un compte iCloud pour utiliser l’application ?

Un compte iCloud n’est pas nécessaire pour utiliser localement Gestion Domicile sur un appareil. En revanche, la synchronisation entre votre Mac et votre iPhone nécessite qu’iCloud soit disponible et que les appareils utilisent le même compte Apple.

Comment synchroniser mes données entre mon Mac et mon iPhone ?

Utilisez le même compte iCloud sur les deux appareils, vérifiez qu’iCloud est disponible, puis activez la synchronisation iCloud dans Gestion Domicile sur les appareils concernés. Les données compatibles sont ensuite synchronisées via iCloud/CloudKit.

Que se passe-t-il si mon Mac ou mon iPhone n’a pas de connexion Internet ?

Vous pouvez continuer à utiliser les données déjà disponibles localement. Lorsque l’accès à iCloud redevient disponible, les changements en attente peuvent être synchronisés.

Mes données sont-elles envoyées sur un serveur du développeur ?

Non. Gestion Domicile n’utilise pas de serveur applicatif propriétaire pour centraliser les données de votre domicile. Lorsque vous activez la synchronisation, les données concernées transitent par les services iCloud/CloudKit d’Apple.

Puis-je utiliser uniquement la version Mac ou uniquement la version iPhone ?

Oui. Chaque application peut être utilisée sur son appareil. La synchronisation iCloud devient utile lorsque vous souhaitez retrouver vos données sur plusieurs appareils compatibles.

Comment sauvegarder ou transférer mes données ?

Sur Mac, vous pouvez utiliser les fonctions d’import / export proposées par l’application. La synchronisation iCloud est complémentaire : elle permet de maintenir les données compatibles à jour entre vos appareils.

Comment fonctionne la reconnaissance des factures ?

Sur les appareils compatibles, vous pouvez scanner ou importer une facture. Gestion Domicile analyse le document afin de proposer automatiquement certaines informations. Vous pouvez vérifier et modifier les données détectées avant de les enregistrer.

Comment signaler un problème de synchronisation ?

Envoyez un email avec une description du problème, la version de Gestion Domicile utilisée, vos versions de macOS et d’iOS si les deux applications sont concernées et, si possible, une capture d’écran. Précisez également si iCloud est activé sur les appareils concernés.

Politique de confidentialité

Dernière mise à jour : 14 septembre 2026

Cette politique couvre les versions macOS et iOS de Gestion Domicile. L’application ne nécessite pas la création d’un compte propre à Gestion Domicile et n’exploite pas de serveur applicatif propriétaire pour centraliser les données de votre domicile.

Données traitées par l’application

Les informations que vous saisissez peuvent notamment concerner votre logement, vos pièces, vos objets et équipements, vos documents, vos entretiens, vos échéances et les informations associées. Ces données sont utilisées uniquement pour fournir les fonctions de Gestion Domicile.

Stockage local

Les données nécessaires au fonctionnement de Gestion Domicile sont conservées localement sur l’appareil sur lequel l’application est utilisée. Vous pouvez utiliser l’application sans activer la synchronisation iCloud.

Synchronisation iCloud / CloudKit

Si vous activez la synchronisation iCloud, Gestion Domicile utilise les services iCloud/CloudKit d’Apple afin de synchroniser les données compatibles entre vos appareils utilisant le même compte iCloud, notamment entre les versions macOS et iOS. Cette fonctionnalité nécessite qu’iCloud soit disponible sur les appareils concernés.

Les données synchronisées sont transférées et stockées au moyen des services iCloud d’Apple dans l’environnement associé à votre compte Apple. Gestion Domicile n’exploite pas de serveur applicatif propriétaire destiné à centraliser ces données.

Documents et fichiers

Les documents ajoutés dans l’application restent associés aux données de Gestion Domicile. Lorsque la synchronisation iCloud est activée et que ces éléments font partie des données synchronisées par l’application, ils peuvent être transférés et stockés via les services iCloud d’Apple afin d’être disponibles sur vos autres appareils compatibles.

Appareil photo, photothèque et fichiers sur iOS

Lorsque vous utilisez une fonction de scan, d’import ou d’ajout de document sur iPhone, Gestion Domicile peut demander l’accès à l’appareil photo, à la photothèque ou aux fichiers. Ces autorisations sont utilisées uniquement pour les éléments que vous choisissez d’ajouter à l’application.

Reconnaissance de texte (OCR) des factures

Lorsque vous scannez ou importez une facture, Gestion Domicile peut analyser son contenu afin d’en extraire automatiquement certaines informations utiles, telles que la date ou le montant, afin de préremplir les champs de l’application. Cette analyse est effectuée localement sur votre appareil à l’aide des technologies Apple. Le contenu de vos factures n’est pas envoyé à un serveur du développeur ni à un service tiers de reconnaissance de texte.

Import et export

L'application peut proposer des fonctions d’import et d’export afin de sauvegarder ou restaurer vos données. Vous êtes responsable de l’emplacement où vous stockez les sauvegardes ou fichiers exportés.

Services tiers

L’utilisation d’iCloud est soumise aux conditions et politiques de confidentialité d’Apple. Si vous choisissez d’utiliser un autre service pour stocker une sauvegarde ou un fichier exporté, les politiques de confidentialité de ce service s’appliquent également.

Support

Si vous contactez le support par email, les informations que vous fournissez volontairement seront utilisées uniquement pour traiter votre demande et vous répondre.

FAQ

Is Gestion Domicile available on Mac and iPhone?

Yes. Gestion Domicile is available as a macOS app and an iOS app. Both apps are designed to use the same data when iCloud synchronization is enabled.

Do I need an iCloud account to use the app?

An iCloud account is not required to use Gestion Domicile locally on a device. However, synchronization between your Mac and iPhone requires iCloud to be available and the devices to use the same Apple account.

How do I synchronize data between my Mac and iPhone?

Use the same iCloud account on both devices, make sure iCloud is available, then enable iCloud synchronization in Gestion Domicile on the relevant devices. Compatible data is then synchronized through iCloud/CloudKit.

What happens if my Mac or iPhone is offline?

You can continue using data already available locally. When iCloud becomes available again, pending changes can be synchronized.

Is my data sent to the developer's server?

No. Gestion Domicile does not use a proprietary application server to centralize your home data. When synchronization is enabled, the relevant data uses Apple's iCloud/CloudKit services.

Can I use only the Mac version or only the iPhone version?

Yes. Each app can be used on its device. iCloud synchronization becomes useful when you want compatible data to be available across multiple devices.

How can I back up or transfer my data?

On Mac, you can use the import / export features provided by the app. iCloud synchronization is complementary: it keeps compatible data up to date between your devices.

How does invoice recognition work?

On compatible devices, you can scan or import an invoice. Gestion Domicile analyzes the document and suggests relevant information automatically. You can review and edit the detected data before saving it.

How do I report a synchronization issue?

Send an email describing the issue, the Gestion Domicile version you are using, your macOS and iOS versions if both apps are involved and, if possible, a screenshot. Please also indicate whether iCloud is enabled on the devices concerned.

Privacy Policy

Last updated: September 14, 2026

This policy covers the macOS and iOS versions of Gestion Domicile. The app does not require a separate Gestion Domicile account and does not operate a proprietary application server to centralize your home data.

Data processed by the app

Information you enter may include details about your home, rooms, items and equipment, documents, maintenance, due dates and related information. This data is used only to provide Gestion Domicile features.

Local storage

Data required for Gestion Domicile to operate is stored locally on the device where the app is used. You can use the app without enabling iCloud synchronization.

iCloud / CloudKit synchronization

If you enable iCloud synchronization, Gestion Domicile uses Apple's iCloud/CloudKit services to synchronize compatible data between devices using the same iCloud account, including the macOS and iOS versions. This feature requires iCloud to be available on the relevant devices.

Synchronized data is transferred and stored using Apple's iCloud services in the environment associated with your Apple account. Gestion Domicile does not operate a proprietary application server intended to centralize this data.

Documents and files

Documents added to the app remain associated with Gestion Domicile data. When iCloud synchronization is enabled and these items are part of the data synchronized by the app, they may be transferred and stored through Apple's iCloud services so they can be available on your other compatible devices.

Camera, photo library and files on iOS

When you use a scan, import or document-adding feature on iPhone, Gestion Domicile may request access to the camera, photo library or files. These permissions are used only for the items you choose to add to the app.

Invoice text recognition (OCR)

When you scan or import an invoice, Gestion Domicile may analyze its content to automatically extract useful information, such as the date or amount, in order to prefill the relevant app fields. This analysis is performed locally on your device using Apple technologies. The contents of your invoices are not sent to the developer's server or to a third-party text recognition service.

Import and export

The application may provide import and export features to back up or restore your data. You are responsible for where you store exported backups or files.

Third-party services

Use of iCloud is subject to Apple's terms and privacy policies. If you choose to use another service to store a backup or exported file, that service's privacy policies also apply.

Support

If you contact support by email, the information you voluntarily provide will be used only to process and respond to your request.
